# Документация проекта

Этот репозиторий представляет собой MVP для управления личными делами школьников.

## Структура

- `src/` — приложение на React + TypeScript
- `src/api/` — мок-API / хранилище данных
- `src/pages/` — страницы приложения
- `src/components/` — базовые UI-компоненты и layout
- `src/store/` — Zustand store
- `docs/` — документация для защиты и разработки

## Основные документы

- `docs/QUICKSTART.md` — быстрое развёртывание
- `docs/DEFENSE_GUIDE.md` — краткое руководство для защиты
