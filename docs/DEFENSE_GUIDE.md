# Guidance for Defense

## Что реализовано

- Реализована RBAC-система с ролями: `admin`, `director`, `teacher`, `secretary`, `parent`, `student`
- CRUD-операции для учащихся и личных дел
- Audit log для отслеживания действий
- Тёмная и светлая тема
- Поиск и фильтрация данных
- Валидация через Zod и формы на React Hook Form
- Состояние: TanStack Query + Zustand
- UI на базе MUI

## Техническая архитектура

- `src/api/mockDb.ts` — мок-сервер данных с локальным хранением
- `src/store/authStore.ts` — управление аутентификацией через Zustand
- `src/hooks/` — кастомные хуки для запросов и работы со стором
- `src/pages/` — бизнес-логика страниц
- `src/components/` — повторно используемые компоненты и layout

## Ключевые преимущества

- Простая, но завершённая end-to-end система
- Хороший уровень типизации и модульности
- Поддержка dark/light режима и адаптивный дизайн
- Тесты на Vitest и RTL
