# Быстрый старт

## Установка зависимостей

```bash
npm install
```

## Локальная разработка

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Тестирование

```bash
npm test
npm run test:coverage
```

## Примечание

- Если будете использовать файл `.env`, скопируйте `.env.example` в `.env`.
- Файл `.env` добавлен в `.gitignore` и не должен попадать в репозиторий.
